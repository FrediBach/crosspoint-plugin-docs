TEXT ADVENTURES (EXPERIMENTAL)

Play Z-machine text adventures (Zork-style games)
on the reader. The games run on a small server on
your computer; the reader shows each turn.

Setup (once):
1. Start the server on your computer.
2. On the reader, start File Transfer, open the
   address it shows, then Plugins.
3. In the "Text Adventures" card, enter the server
   address and press Test & save.

Playing:
- Home > Plugins > Text Adventures, pick a game.
- The first row is the game's last answer. Open it
  to read all of it.
- The other rows are commands. Open one to play it.
- To type a command, go to the top row and press
  Search (Left). Type it like "take lamp".
- Back twice refreshes the command list.
- Fetch on any page saves the transcript to
  /Books/Text Adventures/Transcript.txt
- The game saves itself after every turn.
