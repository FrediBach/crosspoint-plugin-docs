WEB SETTINGS EXAMPLE

This plugin only has a web page. It stores settings in
config.json inside its plugin folder.

How to use:
1. On the reader, start File Transfer.
2. On your computer or phone, open the address shown on
   the reader, then click Plugins.
3. Fill in the "Web Settings Example" card and press Save.

Any device.json placed in the same folder can then use the
saved values as {cfg.server}, {cfg.username} and so on.
