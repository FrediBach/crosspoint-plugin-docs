DEVICE CODE CATALOG EXAMPLE

Sign in to a service by approving a code on your phone
(OAuth device code flow), then browse and download books.

Setup:
1. Enter the server address on the web Plugins page
   (File Transfer > Plugins > Device Code Catalog Example).
2. On the reader open Home > Plugins > Device Code Catalog
   Example and press Confirm to sign in.
3. Scan the QR code (or open the address) on your phone and
   enter the code shown on the reader.

You can also sign in from the web page instead.
