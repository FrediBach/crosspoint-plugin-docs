PASSWORD CATALOG EXAMPLE

Browse and download books from a library server that
needs a username and password.

Setup (once):
1. On the reader, start File Transfer.
2. Open the address shown on the reader, then Plugins.
3. Enter server, username and password in the
   "Password Catalog Example" card, then press Test & save.

Then open Home > Plugins > Password Catalog Example.
The reader signs in by itself from now on.
