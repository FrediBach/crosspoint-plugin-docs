EVENT WEBHOOKS EXAMPLE

Sends these events to your server, without a browser:
- a book was opened or closed (with progress)
- a reading session ended (time and pages read)
- a catalog download finished
and downloads a fresh /sleep.bmp each time the reader
goes to sleep.

Setup: File Transfer > web page > Plugins > Event Webhooks
Example. Enter server address and secret, press Save.
Leave File Transfer so the reader picks up the plugin.

For the sleep image: Settings > Sleep screen > Custom.

The reader turns Wi-Fi on briefly when it goes to sleep
(battery 20% or more, saved network in range).
