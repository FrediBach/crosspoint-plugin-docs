WEBDAV BROWSER EXAMPLE

Browse the folders of a WebDAV server and download books.

Setup: File Transfer > web page > Plugins > WebDAV Browser
Example. Enter the folder URL, for Nextcloud:
  https://cloud.example.com/remote.php/dav/files/USER/Books/
plus username and app password, then press Test & save.

On the reader: Confirm opens a folder, Back goes up.
Downloads go to /WebDAV.
